# Access Control in Cyber Security

Access control is a fundamental security component that dictates who is allowed to access and use company information and resources. 

### The Two Main Components:
1. **Authentication:** Verifying the identity of a user (e.g., using a password, fingerprint, or 2FA). *"Are you who you say you are?"*
2. **Authorization:** Determining what an authenticated user is actually allowed to do or see. *"Do you have permission to open this file?"*

### Common Access Control Models:
* **Role-Based Access Control (RBAC):** Access is granted based on a user's job role (e.g., 'Admin', 'Editor', 'Viewer').
* **Principle of Least Privilege (PoLP):** Giving a user the absolute minimum levels of access necessary to complete their job functions.
